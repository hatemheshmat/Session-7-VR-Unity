void SpawnTargets() { // Loop runs 5 times (0 to 4) for (int i = 0; i < 5; i++) { Vector3 position = new Vector3(i * 2, 0, 0); Instantiate(targetPrefab, position, Quaternion.identity); } }

For Loop Structure:

  • Initialization: int i = 0 (Runs once at start)
  • Condition: i < 5 (Checked before each iteration)
  • Increment: i++ (Runs after each iteration)

Best For:

  • • Known number of iterations
  • • Accessing elements by index
  • • Grid-based operations
i = 0, condition: true

Unity Tip

Use for loops when working with arrays or when you need precise control over the iteration count, such as spawning objects in a grid pattern or processing frames in animation.

void WaitForTargetDestruction() { int remainingTargets = 5; // Loop runs until condition is false while (remainingTargets > 0) { // Check if any target was hit if (IsTargetHit()) { remainingTargets--; } // Important: avoid infinite loops! yield return new WaitForSeconds(0.5f); } ShowVictoryScreen(); }

While Loop Structure:

  • Condition Only: remainingTargets > 0
  • Body: Code that may modify the condition
  • Warning: Must ensure the condition eventually becomes false

Best For:

  • • Unknown number of iterations
  • • Condition-based repetition
  • • Waiting for events to occur
remainingTargets = 5, condition: true

Unity Tip

While loops are perfect for game states that continue until a condition changes, like waiting for all enemies to be defeated or for a player to reach a certain score threshold.

void ResetAllTargets() { GameObject[] targets = GameObject.FindGameObjectsWithTag("Target"); // Loop through each item in collection foreach (GameObject target in targets) { // Access the target directly target.GetComponent<TargetController>().Reset(); } }

Foreach Loop Structure:

  • Element Variable: GameObject target
  • Collection: targets (array, list, etc.)
  • No Index: Cannot access the current index directly

Best For:

  • • Collections (arrays, lists, dictionaries)
  • • When index isn't needed
  • • Cleaner, more readable code
Processing: Target 0

Unity Tip

Foreach loops are ideal for processing collections of GameObjects, components, or data. They're especially useful with Unity's GetComponents() methods and LINQ queries.

Loop Best Practices

Avoid expensive operations inside loops that run frequently
Cache collection lengths outside the loop: int length = array.Length;
Use break to exit early when a condition is met
Consider using for instead of foreach for performance-critical code

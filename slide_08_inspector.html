Tuning Values in the Unity Inspector

Exposing Variables to Inspector

public class ScoreManager : MonoBehaviour { // Public - visible in Inspector public int scorePerTarget = 10; // Private - NOT visible in Inspector private int currentScore = 0; // Private BUT visible in Inspector [SerializeField] private float timeLimit = 60f; // Public BUT hidden from Inspector [HideInInspector] public bool isGameActive = true; }

Why Expose Variables?

  • Tune game values without changing code
  • Allow designers to adjust values without coding
  • Quickly test different gameplay settings
  • Values are saved with the scene or prefab
Approach Visibility Access
public Inspector + Other scripts Read/Write from anywhere
[SerializeField] private Inspector only Read/Write only in this class

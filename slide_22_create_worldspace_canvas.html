Create Canvas (World-Space)

Setting Up a World-Space Canvas for VR UI

Creation Steps

1
Create a Canvas GameObject
Right-click in Hierarchy panel → UI → Canvas
2
Change Render Mode
In the Inspector panel, find the Canvas component and set Render Mode to "World Space"
3
Adjust Scale for VR
Set the Transform scale to a small value (typically 0.001-0.01) for comfortable viewing in VR
VR Scale Consideration
For VR, canvas scale should be small (0.001-0.01) to appear at a comfortable size and distance from the user.

Step 1: Create Script

Create a new C# script in your project:

  1. Right-click in Project window
  2. Select Create → C# Script
  3. Name it ScoreDemo
  4. Double-click to open in editor
// ScoreDemo.cs
using UnityEngine;

public class ScoreDemo : MonoBehaviour
{
    public int score = 0;
    
    void Start()
    {
        Debug.Log("Score: " + score);
    }
}

Step 2: Attach to GameObject

Attach the script to a GameObject:

  1. Select a GameObject in Hierarchy
  2. In Inspector, click Add Component
  3. Type "ScoreDemo" and select it
  4. The script is now attached as a component

Step 3: Press Play

Test your script in Play Mode:

  1. Click the Play button at the top of the editor
  2. Unity enters Play Mode
  3. The Start() method runs automatically
  4. Debug.Log() sends message to Console

Debug Messages:

Best Practices

  • Use descriptive Debug.Log messages
  • Remove debug logs before final build
  • Test scripts in isolation first
  • Check for errors in Console window

Session 7: C# Scripting & UI in VR

Session 7 Assignment

Target Practice Game with Score Display

Project Overview

Create a target practice game in VR that combines C# scripting and UI elements. Players will shoot targets with ray interactors and see their score on a world-space canvas.

Requirements

Technical Requirements

  • Unity 6 with Meta XR All-in-One SDK
  • Proper C# scripting practices
  • TextMeshPro for all UI text elements
  • World-space canvas for UI elements
  • 3+ target types with different point values

Tasks

  • Create a VR scene with room and skybox
  • Set up XR Ray Interactors on controllers
  • Create target prefabs with point values
  • Implement target spawning system
  • Create world-space canvas with score
  • Implement ScoreManager script
  • Add timer system with countdown
  • Create game state management
  • Add visual/audio feedback for hits

Submission

Submission Guidelines

Submit as .zip with all project files, README.md, and demo video (30-60s)

Due: August 18, 2025 at 11:59 PM

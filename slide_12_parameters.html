Value Parameters: Pass a copy of the value. Changes inside the method don't affect the original variable.
void ModifyReference(ref int score) { score = score + 10; // Changes original variable } void Start() { int playerScore = 5; ModifyReference(ref playerScore); // playerScore is now 15 }

Reference Parameters: Pass a reference to the original variable. Changes inside the method affect the original variable.

Out Parameters: Used to return multiple values from a method. The method must assign a value to the parameter.
void SpawnEnemy(string enemyType, int health = 100, bool isBoss = false) { // Create enemy with default or specified values } void Start() { SpawnEnemy("Goblin"); // Uses defaults SpawnEnemy("Dragon", 500, true); // Specifies all SpawnEnemy("Skeleton", 75); // Custom health, default isBoss }

Optional Parameters: Provide default values that are used when the caller doesn't specify them. Must appear after all required parameters.

Parameter Best Practices

Use value parameters for simple data that doesn't need to be modified
Use ref parameters sparingly, as they can make code harder to follow
Use out parameters when you need to return multiple values
Optional parameters make APIs more flexible and easier to use

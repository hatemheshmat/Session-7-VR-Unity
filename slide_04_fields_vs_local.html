Fields (Class Variables) Local Variables
Lifetime Entire object lifetime Only during method execution
Visibility Can be public or private Only within containing method
Inspector Visible if public or [SerializeField] Never visible in Inspector
Memory Stored with the GameObject Temporary stack allocation

Best Practice

Use fields for data that needs to persist between method calls or be visible in the Inspector. Use local variables for temporary calculations or method-specific operations.

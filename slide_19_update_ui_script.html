Part 3: UI & Score Canvas

Update UI Through C# Script

Dynamic UI Updates and Event-Driven Programming

UI Update Event Flow

1
Game Event Occurs
Target hit, health change, ammo used
2
Script Method Called
UpdateScore(), UpdateHealth(), etc.
3
UI Component Updated
Text, slider, image values changed
4
Visual Feedback
Player sees updated information

UI Manager Script

using UnityEngine; using TMPro; public class UIManager : MonoBehaviour { public TextMeshProUGUI scoreText; public TextMeshProUGUI healthText; public TextMeshProUGUI ammoText; public void UpdateScore(int newScore) { scoreText.text = $"Score: {newScore}"; } public void UpdateHealth(int health) { healthText.text = $"Health: {health}"; } }

Event-Driven Updates

// Event system for UI updates public static System.Action<int> OnScoreChanged; public static System.Action<int> OnHealthChanged; // Trigger events from game logic void HitTarget() { score += 10; OnScoreChanged?.Invoke(score); } // Listen for events in UI Manager void OnEnable() { OnScoreChanged += UpdateScore; OnHealthChanged += UpdateHealth; }

Understanding Method Signatures and Call Sites

Method Anatomy

C# Method
private int CalculateScore ( int basePoints , float multiplier ) {
     int finalScore = (int)(basePoints * multiplier);
     return finalScore;
}
Access Modifier: Controls visibility of the method.
public - Accessible from anywhere
private - Only within this class
protected - This class and derived classes
Return Type: The type of data the method returns.
void - Returns nothing
int, float, bool - Returns that type
GameObject, Transform - Returns Unity objects
Method Name: Identifies the method.
Use PascalCase naming
Descriptive of function
Often starts with a verb
Parameter Type: The data type of each parameter.
Any valid C# type
Multiple parameters possible
Order matters when calling
Parameter Name: Identifies the parameter within the method.
Use camelCase naming
Descriptive of purpose
Referenced in method body
Return Statement: Sends a value back to the caller.
Must match return type
Exits method immediately
Not needed for void

Common Method Types

  • Unity Event Methods: Start(), Update(), OnTriggerEnter()
  • Helper Methods: CalculateDistance(), IsPlayerInRange()
  • Getter/Setter: GetHealth(), SetScore()

String Concatenation Builder

Common String Operations

Length Property

Gets the number of characters

string name = "Unity";
int length = name.Length; // 5

Substring Method

Extracts part of a string

string text = "Unity3D";
string sub = text.Substring(0, 5); // "Unity"

Key Points

  • Strings are immutable (unchangeable)
  • Use + operator to combine strings
  • String interpolation is more efficient
  • StringBuilder for complex concatenation

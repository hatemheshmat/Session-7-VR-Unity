World-Space Canvas Optimization Strategies

Canvas Performance Impact

World-Space canvases can impact VR performance through draw calls and batching. Optimizing UI elements is crucial for maintaining frame rate in VR applications.

Each material = draw call
Same material = batched
Unbatched UI (10 elements) 10 draw calls
High Impact
Batched UI (10 elements) 1-2 draw calls
Low Impact
Optimization Tips
• Use same TMP Font Asset across all text elements
• Minimize canvas count - use a single canvas when possible
• Disable unused components like Raycast Target

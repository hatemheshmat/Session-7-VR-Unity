Common Numeric Types

int vs float differences and casting basics

int

Integer (int)

  • • Whole numbers only (no decimals)
  • • Range: -2,147,483,648 to 2,147,483,647
  • • 32-bit signed integer
  • • Use for: counters, indices, whole values
int score = 100; int playerLevel = 5; int totalPoints = score * playerLevel;
float

Float (float)

  • • Decimal point numbers
  • • ~7 digits of precision
  • • 32-bit floating point
  • • Use for: positions, speeds, percentages
float speed = 5.75f; // Note the 'f' suffix float distance = 12.3f; float time = distance / speed;

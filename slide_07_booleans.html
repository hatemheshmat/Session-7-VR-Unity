Booleans

True/False Flags and Conditional Logic

Boolean Basics

  • Only two values: true or false
  • Perfect for flags: Track states like "isJumping", "isGameOver"
  • Used in conditions: if statements, while loops
public class PlayerController : MonoBehaviour { public bool isGrounded = true; public bool hasKey = false; void Update() { // Boolean in if statement if (isGrounded && Input.GetButtonDown("Jump")) { Jump(); isGrounded = false; } } }

Boolean Operators

&& (AND): Both true
|| (OR): Either true
! (NOT): Inverts value
== / !=: Equality check

Interactive Boolean Logic

hasKey:

{
Jump(); // Player jumps!
isGrounded = false;
}
if (hasKey && nearDoor)
{
UnlockDoor(); // Door unlocks!

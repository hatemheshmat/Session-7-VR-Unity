TextMeshPro Overview

TextMeshPro (TMP) is Unity's advanced text rendering system that replaces the standard UI Text component with improved quality and features.

1
Open Package Manager

2
Find TextMeshPro

3
Install Package
Click "Install" button to add TMP to your project
4
Import TMP Essentials
When prompted, click "Import TMP Essentials"
